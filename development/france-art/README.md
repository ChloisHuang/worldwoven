# 法国原画展览与本地艺术师

CR01 / CR02 / CR06 / W03 子批。现有法国原居民没有可证的个人买画钱包，免费下午茶不是订单来源。本批实现有限原创展览，不伪造顾客、采购款或艺术销售。

- 原卢西安与同一画坊：六套一次性画布/颜料，持久 `france-exhibition-six-v1` 标记；每天最多起一幅，无自动补货。
- 玩家在职业手册选择花园/柱廊及晨光/暖暮，按同一编号登记、领料、描稿、上色、携画、由卢西安来到陈列处核号后归档。未开班由同一原画师制作；取消先把实物带回画架，再由NPC续做。
- 每件保留实际作者、题材、同号耗材及实体画面。北墙右侧实墙六格展示，附近可读原画目录；原学习画架和艺术课源码接线未改，未重跑其现场课程或原日需，不称那些流程本批已验。
- 本地唯一席位需18岁、艺术2/文书1。16法国券满班固定工资通过既有正式公共雇用/银行接口按真实工时结算，不是每次点按钮或卖画收入。作为新增游戏设计，对照法国现侍茶10、糕点14与正餐4券；不称历史工资或真实财政模拟。
