# Isolated anatomical head study

Prototype only, based on verified CC0 MakeHuman hm08 static mesh data. No MPFB addon/code is downloaded or run. `assets/upstream/provenance.json` pins the upstream commit and SHA-256 of the exact base mesh and license texts. Upstream license sections C–D and the mesh's own September 2020 CC0 header agree. Original authoring script crops the body/helper geometry, fits an adult head/neck to Worldwoven's axes/scale, and adds original eye globes and tapered brows.

The visual direction comes only from the supplied sglynp references. Their identity, scars, textures, and images are not copied into the asset or committed. The same brown skin/hair, French outfit, adult masculine-lean body and original round06 side-part framing are retained in the cel comparison.

Run `blender -b --factory-startup --python development/anatomical-head/build_head.py`, then `CLAY_STUDY=1 OUT_DIR=$PWD/qa/anatomical-head/clay01 node development/anatomical-head/render.mjs` and `OUT_DIR=$PWD/qa/anatomical-head/cel01 node development/anatomical-head/render.mjs` under the agreed 175-second/1.2-GiB process-tree guard. Each output directory must be new. Gray clay hides hair/brows to expose anatomy; the cel run uses the unchanged production material ramp and lighting, without the legacy face-lighting-floor override.

Not production-integrated: the imported head/neck currently uses the head classification in the isolated renderer. Blended cervical skinning, existing randomized facial controls, body/hairstyle/pose validation and final neck/collar integration are still required. No all-parameter matrix is claimed. The visual result must be assessed against the reference before any integration proposal.

## 2026-10-03 visual result

Source/asset stages: `82d3ad7` (pinned CC0 data and scripts), `7612ffc` (fitted derived mesh). Final inspected images are local-only `qa/anatomical-head/clay03/clay-{front,threequarter,side}.png` and `qa/anatomical-head/cel03/cel-{front,threequarter,side}.png`; render images and logs are excluded from Git.

**Verdict: stronger anatomical foundation, not an accepted art replacement.** Gray clay shows continuous nasal wings/nostril recesses, formed lip rolls, an actual mandibular underside, eye sockets and detailed ears. These are materially better anatomical building blocks than the old procedural face. The final restrained eye-width adjustment, flatter brow and upper-cranium fit keep the retained original hair from exposing scalp patches. The supplied skin color is unchanged.

The cel result still reads as a generic stylized base. In particular, the eye opening/globe/iris relationship needs an authored character pass, lip shading retains a thin light return at the mouth seam, and the broad cheek tonal bands do not achieve the supplied reference's refined facial treatment. The default hm08 mesh alone is **not suitable as the finished requested aesthetic**. Keep it separate; do not merge the loader into production based on render success. The neck is still too broad/straight and joins the jaw too heavily; its cropped opening needs fitting/blended weights before animation integration. The 39,984-triangle study is a sculpt evaluation asset; a lighter game mesh should follow the art decision, rather than expanding this phase into rig/parameter tests. Original facial controls and all body/hairstyle variants remain unimplemented and untested.

Checks chosen for this isolated geometry study: source syntax, three-angle gray form review, three-angle exact production-material review, clean renderer/resource disposal, source-file preservation and the agreed process-tree guard. No gameplay/all-body matrix was run because no production or interaction source changed. Final Blender build: 3.17 seconds, 251,211,776 bytes peak observed RSS; final clay: 1.51 seconds, 248,606,720 bytes; final cel: 1.51 seconds, 273,399,808 bytes. All exited 0, no shader/GL errors, zero remaining character references. Mesa's unwritable optional cache was disabled by the runtime and did not block rendering. The study has 24,791 exported vertices / 39,984 triangles, including duplicated per-material globe vertices.

Verified official licensing sources: [asset/code separation](https://github.com/makehumancommunity/mpfb2/blob/afb9f530a7c2741dedb8df0ebae2e0b183caec21/LICENSE.md), [CC0 legal text](https://github.com/makehumancommunity/mpfb2/blob/afb9f530a7c2741dedb8df0ebae2e0b183caec21/LICENSE.ASSETS.md), [official closed-source FAQ](https://static.makehumancommunity.org/mpfb/faq/use_in_closed_source.html). The header and the two license files are preserved unmodified with SHA-256 provenance.

Mouth-seam diagnosis: no teeth geometry or teeth material is imported (all tooth/helper groups are excluded). The bright central seam pixels are skin-colored (peak RGB 188/138/103 in the inspected region), not the background (217/221/207), so this is a lit skin/mucosal return rather than exposed background or white teeth. This should be corrected locally without rebuilding the full face.
