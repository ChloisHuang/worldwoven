# Original Blender adult control cage — unaccepted WIP

This is a new editable mesh, independent of the earlier height-field face. The source is `build_control_cage.py` and `assets/adult-control-cage.blend`; the .blend keeps a half-head cage with Mirror and two levels of Catmull–Clark Subdivision. Eyes, nose cavities and the mouth use explicit face boundaries and loops. `assets/adult-subdivided.json` is the original evaluated render mesh, not a source snapshot. No reference image or downloaded asset is embedded.

Current cage: 304 control vertices / 271 faces; evaluated study including eyes, ears and brows: 20,544 triangles. Mouth loops now terminate in local cheek patches instead of extending as head-wide rings. The jaw underside connects to a separate posterior cervical loop rather than squeezing the chin into a neck funnel. The orbital rings have shared face edges, a lid fold, a thick front edge and an inner return. Editable outside Shrinkwrap constraints keep the subdivided rims clear of the same closed globes. The iris remains on the globe, with upper-lid coverage. The mouth has a closed inset cavity and turned upper/lower lip sections; a subdivided point attribute carries the lip tint instead of rectangular material bands. Normal gray front/three-quarter/side views and one matching cel view are available locally, but the jaw, mouth, eyes and whole shape remain unaccepted. This is not a production replacement or an approved character system.

Build with the installed Blender 4.3.2: `blender -b -t 2 --python development/blender-face/build_control_cage.py`. Use the existing bounded runner. The existing local renderer accepts `WHOLE_FACE=1 BLENDER_FACE=1 CLAY_STUDY=1` and `VIEWS=front,threequarter,side`. Omit `CLAY_STUDY` for the production skin toon ramp, with the existing eye-only reflection. The earlier bright face-only ramp is disabled for the Blender study. Generated review images stay outside Git.

Verification is limited to successful bounded asset builds, the earlier normal gray three views, and current normal front/three-quarter views under the actual production skin toon ramp. The latest build/render took 2.6/1.8 seconds and stayed below 281 MB observed RSS. Current forehead/cheek cel transitions and the complete face remain artistic WIP. Rig/appearance integration, shape-parameter mapping and artistic acceptance remain pending.

The saved cage uses broad cheek/skull spans outside the mouth, with local quads and a few cheek transition polygons. This is a construction checkpoint, not a claim that using Blender establishes artistic quality. The current cel appearance still needs work after the shape is judged usable.
