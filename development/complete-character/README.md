# Complete representative adult

The source/reference direction is one coherent original adult wearing the existing France outfit. The supplied Sims images were visually inspected but are never imported as geometry or texture. Skin/hair/iris colors remain the original selected values.

Authoring changes method: editable named anatomical handles in `cage.json` deform the pinned CC0 hm08 surface with one thin-plate cage solve. Direct topology loop edits then close the lips and seat the orbital rims. Blender retains a Basis plus Sculpt shape key and an inspectable cage object; no stack of Gaussian micro-displacements is used. The source attribution is retained under `../anatomical-head/assets/upstream/`.

This isolated branch does not replace production characters. Final complete comparison and resource counts are recorded after actual render review.
