# ST04 · 浴池误入、隐私与关系反应

2026-10-07，基于 R16.174 源码的候选实现；未发布，浏览器/实机接受仍开放。原母项要求保留：误入按当下隐私需求、关系、喜好与情境提醒/退让/关系后果及合法后续；外貌不豁免侵犯，不羞辱，亲密仅成年人双方自愿可撤回、非露骨。

## 已实现

- 普通走路穿过原区域也会触发，不依赖点浴具。1秒一次区域检查，只在当前玩家进入实际浴室时查询在场人物，逐人同楼层、同房间和原遮挡射线筛选，空房只有标识提醒，无虚构关系观察者。
- 当前更衣/擦干/清洗须原任务真正到位，泡澡须原挂载/过池沿动作；关系影响说法，疲劳/安静喜好影响共享池个人距离。私人浴间仍要求先退，熟人和外貌都不豁免。
- 日本汤区沿原浴牌/现有身体预设分区。无浴牌也不准点进另一汤池，但误走门内会提醒。实际当班配送或持原包时，限定原服务侧通道允许过路；离开服务通道不获豁免，当班也不能进入错侧池座。未放宽原牌、更衣、清洗、浴包或付款条件。
- 原E/触屏当前动作“退到公共通道”使用原导航、门和碰撞走回公共处，也可自己走。点按钮不等于退出；日本洗浴区与更衣间间的内门不算公共退让。真正退出才有微量定向尊重；同日同区域同人去重。界面选择/总览、确实尝试退让而被门路阻挡，不当作故意侵犯。
- 已明确提醒后仍在原在场人物边界内停留8秒，记实际知情者→玩家的信任/好感下降与厌恶；没有全图声望惩罚。后退不抵消既有失信。稳定事件ID、持久待投递、失败重试及原关系账本去重，离区/重载不伪造一次完成。
- 对等保护玩家：实际沐浴/过池沿时，NPC原移动在独占浴间入口或共享池1.1米近身边界等待，提示留空间。只限制当前尝试越界的移动，不全帧扫NPC，不夺岗位控制或把人传送走。NPC离开方向不拦；玩家原E/移动离池始终可用，离池后原NPC路线继续。有人还在独占浴间时先不准挂载，避免把在场NPC突然困住。
- 后续沿ST01原关系接口与实际话题：记得退让/未退让，可以在公共处进行原有交谈。真实浴池过错即使陌生也可提出原定时道歉；是否接受仍按原意愿判定，不自动和解、不刷亲密。原道歉已承认/修复的证据会改变后续记忆说法。
- 浴室内不生成亲密互动机会。公共后续全四国可用；中国有真实合法房权时仍走ST01/ST02原成年、当次双向确认、原导航和非露骨淡出。其余三国没有既定双人房权，不造“过夜”捷径、同意、免费服务或伴侣身份。ST06替代提案未扩写。

## 保留边界

- 不把只有日本具备的自主泡澡日程说成四国都有，不为展示功能刷NPC或给其他国家新造故事日程。
- 本项未增加玩家可购买的私人汤房、同浴邀约、服务收费、犯罪/追捕或ST06机制。
- NPC服务等候沿原拥有者恢复；没有虚构服务完成、工资、健康缓解或私人房权。
- 外观/几何未改，复用原浴池与服装证据；新增提示在真实浏览器/手机上的最终视觉接受仍待验。

父审定点接续：隐私提醒不再覆盖已坐下、过池沿、待起身时的原控制。原取消函数本来就会启动离池，未发现离池卡死；实际修复的是“等待出口时E取消起身”被遮挡的问题。新增生产 `currentControl`/`executeNearbyAction` 抽取小测验证离池、过渡、取消等待、离池后退回公共处四分支；25/25新轻测通过，原24直接依赖和416帧main证据复用，未重跑整main。
