# 锦衣卫训练服：造型依据与边界

本次只替换 `jinyi-training` 的服装构造与附加冠帽、带鞘腰刀，不修改原人物面部、体型参数或共享骨架。所有可见网格与简化云纹均为代码原创，没有使用影视造型或文物图片作为游戏资产。

## 已直接查看的馆藏图像

- 故宫博物院刊物图三一「明 香色麻飞鱼袍」，PDF 第3页、印刷页76：<https://www.dpm.org.cn/Uploads/File/2019/08/27/u5d650926f3660.pdf>。已渲染并查看原图：右衽交领、收腰、密褶下裳、阔袖收口与横向膝襕。游戏提取收腰/褶裳/束口袖的轮廓，训练袖宽按动作做适度收窄；未复制实物飞鱼织纹。
- 国立故宫博物院「明人画出警图 卷」（中画000054），已直接查看馆方分段图像中的黑冠、彩袍、束带、骑乘与腰间佩具：<https://digitalarchive.npm.gov.tw/Collection/Detail/1624?dep=P>。画卷中服色、帽式、甲胄随身份和用途有差别，游戏用黑色折叠冠的简化轮廓，不把整幅画的人物统称同一制服。
- 国立故宫博物院「明宣宗马上像 轴」，已通过馆方在线图像查看：<https://digitalarchive.npm.gov.tw/Collection/Detail?dep=P&id=1857>。其右衽长袍与运动场景作为辅助参照；皇帝的帽饰及纹样不移植给普通训练守卫。

## 不作过度历史断言

故宫博物院《明代官员服饰研究》印刷187页，列举嘉靖时期特定祭祀时锦衣卫堂上官的大红蟒衣、飞鱼服、乌纱帽、鸾带、绣春刀，与另一些场合的大红便服之区别：<https://www.dpm.org.cn/Uploads/File/2019/11/25/u5ddbb3f9e989e.pdf>。

国立故宫「牙雕异兽饰件」也说明斗牛、飞鱼原是须赏赐的尊贵纹饰：<https://digitalarchive.npm.gov.tw/Collection/Detail/45428?dep=U>。

因此本次命名为「明式训练袍」，不宣称全体锦衣卫都穿飞鱼服，也不宣称简化腰刀是某件传世「绣春刀」的精确复原。帽、云纹、带牌及刀装均为适应原游戏赛璐璐风格的克制原创概括。没有为训练守卫虚设官阶补子。

## 接入与验证

`buildJinyiGarments` 进入原有模板塑形、袖部权重及布料骨骼流程；`attachJinyiCostume(actor)` 仅附加头骨帽与骨盆腰刀，并返回幂等 `dispose()`。管理岗位的 routine 负责替换旧 `dressGuard`、保存句柄并在角色移除前释放。

2026-10-04 验证：JS 语法与增量 diff 检查通过；用实际角色模板、骨骼和原练习弓渲染两名守卫静立、引弓与一次行走姿态，并直接看图。右衽领向与实物正面一致；带、褶裳、帽与鞘刀轮廓可读，袖口随引弓抬起，步行裙裾随腿变化且不露出腿部穿透。原共享 surface 对周向采样的限制曾使褶裥过平，已只在本服装使用足够的采样修正。局部图片在工作目录 `qa/jinyi-costume/`，不作为游戏资产提交。真实宫苑普通 TPS 与岗位交班由巡查整合批次复核；此处不扩大到全服装/全体型矩阵或手机实玩结论。
