# S03 · 当前楼层与逐间到达核对

2026-10-07，核对基线 `cc06828`（R16.168 护栏产品候选）。原验收：中国全部房间/阁楼、日本客房、埃及地上地下从正常入口到达；地坪/台阶衔接，无断层、悬空或瞬移；楼梯接公共走廊/前室。法国也核对实际适用空间，不凭空增加上层。S04 只核对与入口链直接相关的客房隔墙、楼梯出口，整体围护/沉浸镜头仍独立开放。

## 结果与证据边界

本轮没有发现需要修改产品的楼层断连。保留全部代码、门锁、入住/岗位/隐私规则及家具位置。不是新增一套导航、解锁所有房间或从床边起点代表入口完成。

范围复用 [D05逐间清单](d05-entry-audit.md) 的118个登记入口及其明确补列的无登记公共/地下空间；入口数量不是房间数量。中国50条用途记录含重叠茶厅/梯厅，不能宣称50个独立封闭房间。已验证楼梯与业务链见 [S01/S02实际接点](../development/guardrails/README.md)、[云来整栋](../development/yunlai-layout/README.md) 及下表。此次只补普通入口到室内的缺失连接证据，不重复所有梯段、不运行日程/经济长模拟。

新增检查使用真实生产场景、自动门 `planPath/update`、`followActorRoute` 与 `moveActorWithCollision`，.34m身体、1.95m身高，门叶按近距正常开合，连续逐步移动到目标；未设置门全开、忽略碰撞或改动位置实现到达。组件几何通过不等于主场景业务权限通过：私室/客房/浴厕的合法使用资格和有限占用沿用已有业务证据，未授权拒绝保持原样。没有重演住宿、任职或宫廷申请。

## 日本：客房与楼层关系

现行唯一公共客房为三层 `guest-suite`。正常到达是三层楼梯北上口→东侧公共走廊 `[6.55,7.6,-6.9]`→原 `jp-guest-suite-door` 门前→原房内探索点，再从同门退回公共走廊；4条生产自动门/身体实走全部通过。卧榻位于实体东隔墙西侧，楼梯北口不直接开到床边。三层 library 与大炬燵厅、其余楼层/附属空间按D05用途表保留；原三组梯、四阳台、楼板洞口与原客房走廊双向通过证据复用R168，不重新扩成日方全部日程验证。

旧 `japan-structure-r12` 的静态墙封闭断言在 `[-.63,7.6,-8]` 仍会失败：当前此处属于后加推拉门袋口构造；该测试只查静态墙碰撞，未实例化当前自动门。另在该x位置从走廊向墙面发射.5/1.5/2.6m三条真实网格射线，均命中z≈−7.81及−8.13的两侧实体，证实该中面点不是穿透开口。不能称完整R12通过，也不能由它推出当前客房缺墙。本轮正常门入口/退回通过，未修改围墙、门袋或测试断言；S04更广的视觉/镜头验收仍开放。

## 埃及、法国

埃及38段、5,484个移动步通过，采用当前 `egypt-temple.js`，排除旧 `regions-west.js` 中未使用埃及构造：

- 地面21段：正常出生点→主前门→厚石甬道→公共前庭，接审判厅、王室起居厅、寝室、浴室/北WC接近点、餐厅、厨房、储物室、彩绘柱厅，最后接地下梯口与上升梯脚。
- 地下转折2段：已验第一梯下端→公共转身廊→第二梯上口。
- 深层9段：已验第二梯下端→前厅→西祭品室→主墓室→东罐室→东西侧廊→前厅及梯口返回。祭品/罐室未因不在入口登记表内而遗漏。
- 上层6段：已验上升梯顶→公共平台→王殿入口→王殿/西侧廊→平台返回。楼梯先到公共平台。

法国20段、2,860个移动步通过：正常出生点→前庭→门廊→前门→镜廊，连续接沙龙、糕点房、浴室/WC接近点、暖房、艺术书斋、餐厅、音乐厅、寝室，共9房及东西各前后4条连接廊，最后经镜廊原前门退出。沿已执行路线用原 `visualSupportHeight` 核对9,147点，最大相邻地坪变化.128m；原15个行走面、最高.489m仅WC脚踏。法国原平层根节点导航不能误当成缺地板，没有可供补验的上层居室。

埃/法所有终点水平误差≤2.45cm，埃及楼层高度正确。原门正常开合，未预开门/解锁。浴厕只走空闲入口和接近点；原 `egypt-daily-toilet-main` / `france-daily-needs-main` 隐私占用及让位/闭门证据复用。自选埃及回程点 `[-8,0,10.5]` 首轮被拒，经实际柱脚/柱身碰撞体查证为正确拒绝；它不是产品入口。换回已有接待处目标后续17段全通过，前段不重跑。临时WC目标ID拼写修正也不是产品问题。原始证据在 `qa/s03-west/`。

## 不扩大结论

本轮为组件级实际几何/正常自动门/行走链与未改接点证据复用；没有浏览器/GPU/iPhone动态实玩或新的用户视觉接受。没有产品几何改动，故不为本次核对制造新渲染、源码构建、永久测试入口或全世界验收。S03当前代码覆盖核对通过后仍保留实机/用户接受边界；S04的完整围护和镜头母项不因此关闭。一次性原始日志与调查脚本位于本地 `qa/s03/`，不加入日常回归门槛。
