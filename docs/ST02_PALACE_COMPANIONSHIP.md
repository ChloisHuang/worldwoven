# ST02 成年宫廷关系：原寝殿自愿相伴

本批直接接 [ST02 / CN07 / CR04](PROJECT_CHECKLIST.md)。既有自荐、真实召见、同册授妃/请册后、独立住房与御膳保留。新增的不是政治授册，也不凭名位、好感或付款取得同意。

## 实际链

- 现职皇帝由场景真实 `royalRole` 唯一绑定解析，命令保存真实 `actorId`、当时身份/岗位版本及演员引用。角色替换、死亡、未成年、房权或当晚状态失效取消原令，不把旧令转给新任。
- 皇帝晚间有界机会先决定是否邀约，再按各人的关系/偏好选择；对象来自当前中国真实 roster。双方须已在 ST01 实际互表好感，每个人仍独立决定当次意愿。
- 玩家没有现行可取得的皇帝职位，因此普通玩家没有翻牌发令按钮。玩家可当面提出相伴请求，由真实皇帝当次回应；提请本身不表示玩家同意。皇帝选牌、延迟传召、本人明确回应、前往原寝殿为持久的同一邀请。
- 受邀玩家从原地的当前安排答复，也可收起暂不答复。NPC 自主答复有保存的单次概率结果；疲劳、饥饿、个体关系/信任/偏好都影响意愿。拒绝与撤回不罚关系。
- 仅双方同意且原职责允许离岗才借用身体，复用 ST01 社会租赁、真实导航/门及家具 claim。原雕龙龙榻标明既有 `bedroom` 归属，双人站点沿原东侧通道，不改几何、不登床、不新增房间。
- 两人真实来到同一原寝殿站点后才进行十秒非露骨淡出；玩家可随时结束。NPC 配对只隐藏当次参与者；结束或取消释放寝殿/身体并恢复原控制器。政治名位、薪资、住房所有权和食物账本不变。
- 完成按原稳定邀请 ID 一次记入双向 ST01 关系结果。读档中间态安全取消，不恢复身体占用或补发结果；完成记录重载不重复奖励。存储失败立即释放身体，未提交奖励回滚。

## 适用角色与边界

所有当前中国成年角色及真实替任身份都进入共同资格检查，不写死人物姓名。当前岗位名单对应 [ST01 31 人逐岗覆盖](ST01_NPC_COVERAGE.md#逐人覆盖)：

- 原皇帝与三妃：原宫廷日常控制器；召集/朝议、已坐卧、用餐、如厕和急需优先。没有把既有妃位作为同意。
- 六官：工部、仓务、礼部、吏部、刑部、录事；原公务/朝会、借用就餐/看诊/雅集控制器优先。
- 传令、书写、庭园、茶主人、原稿管理：当前绑定与真实任务优先；只有原岗可短聊、未有离岗许可时不能被召走。
- 御膳厨役、两守卫：原制作/交班/值守与急需控制器决定能否离岗。
- 酒楼掌柜、厨役/帮厨、东西食客：实际任职、接待、持物/送餐/收洗以及看诊/雅集借用优先。
- 雅集接待及诗/书/曲/棋四艺人：实际接待/表演、客人等候与当班覆盖优先。
- 医师、药房、钱庄出纳：治疗/配药/交易优先。当前钱庄等没有真实替班释放的岗位，不拿原地聊天许可冒充离岗许可。
- 玩家：已有真实册妃/普通身份均不能绕过双向关系及当次同意；当前工作、就寝、沐浴、治疗、御膳/其他身体控制优先。

其余三国不套用中国宫廷召令；普通跨国社交仍走 ST01。妊娠/生育/亲缘及继承为 ST08，犯罪为 ST05，ST06 替代玩法不在本批。
