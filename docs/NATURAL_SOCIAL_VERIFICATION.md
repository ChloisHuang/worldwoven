# ST01 / ST03 自主邀约实际发生核查

## 原需求及交付边界

用户反馈「目前没有看到青楼点人和 NPC 互相邀约」。原 ST01 要求当前四国真实 NPC 双向互动、可见移动、本人回应和原职责恢复；ST03 要求中国艺者服务的真实资金、本人意愿、房间和完成结算。接口能调用或预置邀约不能代替正常日程证据。本候选修共享公共社交接点，尚未完成自然 main 终态验收，不关闭母项，也未发布。

## 本候选改动

- 玩家距离或楼层导致的 `root.visible` 渲染剔除，不再剥夺仍在场 NPC 的公共社交资格，也不把未渲染的人当作空房。
- 每个原18秒机会只从实际同层、可互见邻居中抽选发起者，保留原一次行动及一次目标/回应抽样；孤立角色不再耗掉所有机会。没有提高行动或接受概率，没有筛选幸运随机种。
- 对已获原 owner 离岗许可的发起者，补真实短程走近→问候→当次回应。对方留在原位置；导航、身体碰撞、死亡、身份变更、急需与职责优先仍有效。原路线和任务进度不被改写。
- 普通公共短聊可在实际相遇处完成，不必把云来楼邻居强制送到正殿；明确的公共赴约仍走原会面设施及许可。没有借此允许未放班的出纳/工作人员离岗。
- 浴区、含床寝室与客房不作为公共问候地点；私人相伴仍为独立的成年、当次双方同意及合法房权流程，钱款不替代同意。
