# 四方生活 · 全项目进度总览

截至 **2026-10-05，R16.75 / Sites v103**；[正式游戏](https://alien.doudouai.net/)。本表涵盖主清单及归档的全部模块，不限于今天新增的内容。

**现在已有四国可探索场景、多条真实 NPC 服务链、部分可任职岗位、钱庄与经营账务；人物整体美术、全职业覆盖、完整生活与故事系统仍未完成。** 学习XP、持久待审与实体任命、按场所负责人办理招聘首段已于R16.74上线；完整职业树与所有场所面板仍未完成。

读法：**范围完成**只指该行列明的窄范围；**首段上线／整项未完**不能算整项完成；**重开**表示用户实玩已提供新反例，旧成功记录不能覆盖它；**排队**表示已授权、按优先级和依赖继续，并非等新许可。真实 iOS 的画面、操作和性能仍有未验部分，不将模拟 DOM、Three/Mesa 或离线 SVG 检查写成手机验收。
