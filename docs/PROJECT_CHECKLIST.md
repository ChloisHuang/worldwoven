  - 强暴/性暴力玩法不制作。已说明可改为非性暴力的骚扰、威胁、求助与追捕事件，以保留冲突和救助的故事感。
  - 这是提出的替代方向，不记为用户已确认的额外机制；具体内容与ST05的衔接待后续设计确认。
- [ ] **ST07 · 隐性人物状态与行为因果** — 低优先级，待设计，未开始
  - 分别建模声望、知名度、支持者数、道德/正邪倾向与健康状态，不合并成单一总分；支持者关联实际NPC关系及立场，不能凭空累加人数。
  - 行为改变本人状态及不同人物/阵营对其评价和关系；长期不吃饭、持续过量饮食等生活行为影响游戏内健康，并产生可追溯的后续反应。
  - 状态组合与人物关系、职业技能及情境共同解锁额外行为选项、调整成功概率和连锁后果；不是数值达标就必然成功，具体权重、阈值和变化规则尚待设计。
  - 隐性数值不直接显示为状态条，通过对话、待遇、人物行为与身体表现反馈可理解的因果；任何隐藏状态或组合选项都不能绕过成年人、自愿、可拒绝等既有边界。

- [ ] **ST08 · 年龄增长、妊娠与亲缘事件** — 低优先级，待设计，未开始
  统一记录游戏时间妊娠进度、非露骨出生事件、皇子/皇女与亲缘关系，以及儿童、成年、老年阶段；具体时间尺度与概率未设计，不在当前宫廷首批加入儿童。
  成年年龄资格是ST02/ST03及所有亲密邀约的前置依赖：儿童和未成年必须在候选生成与动作执行逻辑中完全排除，不能只隐藏UI；任何关系/魅力/价格/房间状态都不能绕过该资格及自愿边界。

## L. 后续职业与地下黑市（低优先级，排在ST故事系统之后）

2026-10-04新增需求记录。以下全部**待设计、未开始**，仅保留后续需求，不在本批实现。玩家选择、人物性格、关系与情境变化应产生不同人生路径，不设唯一固定剧情。

- [ ] **CR01 · 各国职业树与求职登记处** — 待设计，未开始
  - 本地化职位登记处须可查看真实职位空缺、职责、工资和门槛，提交申请并收到结果；与实际职业树和岗位状态相连，不能只是牌子。
  - 各国建立本地化、独立的职业体系与申请处。缺乏身份地位、钱、人脉和技能的新来者，可从符合条件的打下手岗位起步；用户“只能选一次”暂理解为选择首份入门职业，不锁死永久转职，具体含义后续澄清。
  - 御膳房仅为示例，职业族还包括医药、守卫/锦衣卫、商贸/钱庄、艺人/酒楼、汤屋服务、工匠等，按各国空间、文化和岗位用途展开。
- [ ] **CR02 · 工作学习与成长** — 待设计，未开始
  - 通过做工、积累经验、旁观学习提升技能，并发展人脉与声望；成长与实际岗位活动、人物回应和机会相连。
- [ ] **CR03 · 职位工资、晋升与转职分支** — 待设计，未开始
  - 各职位有相应工资、申请与晋升条件、跨职业转换门槛和不同发展分支；条件与技能、经验、身份、关系及声望关联，兼顾正途成长与外交协商。
  - 各职业提供适合自身的专业成长、经营社交、权力或违法风险路线，不机械套用同一模板；将职业能力、可操作行为、人物关系、后果与世界事件组合，支持跨职转型、失败恢复和多条达成路径，而非几条固定任务线。
- [ ] **CR04 · 职业选择与宫廷阴谋事件** — 待设计，未开始
  - 御膳房示例：精进烹饪获得赏识和晋升，或参与虚构的材料走私、药剂事件及宫廷继承/夺权故事。阴谋、诬陷与外交作为有分支的游戏事件，包含调查、证据、失败反噬及法律政治后果，不能自动成功。
  - 仅设计非现实机制；不加入真实投毒材料、配方、剂量或现实诬陷操作指南。
- [ ] **CR05 · 地下黑市空间与经济** — 未来待建，待设计，未开始
  - 独立建设地下黑市及其交易与经济系统，衔接材料来源、岗位工资和职业分支，并与ST05巡查、追捕及牢房故事互联；不能只放一个可无限获利的交易按钮。
