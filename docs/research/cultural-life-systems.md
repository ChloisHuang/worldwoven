# 四区社会生活参考（仅研究，系统尚未实现）

研究日期：2026-10-04。仅供后续设计与 backlog，不代表已实现。目标是让工作、家庭、关系和制度共同生成不同人生，而非给同一套后宫玩法换皮。

## 共用基础与史料边界

- 共用年龄成长、监护/学习、成年职业、友情/恋爱/婚姻、可选怀孕与育儿、衰老照护、死亡和继承；各区替换机构、资格、资源和事件规则。文化不决定人格。
- 先过滤合法可行动作，再按人格、需求、体力、心情、技能、关系、义务、地点和近期事件加权抽样；保留少量探索概率与冷却。日志说明原因，避免每天均匀随机抽戏剧事件。
- 工作必须有准备→执行→交付→收入/评价的过程，消耗材料与时间；失败可补救，同行可合作、竞争、顶班，照护责任会改变排班。
- 全部亲密、孕育与付费陪伴机制仅限明确年满18岁的成年人，自愿且可撤回，非近亲，非露骨淡出。未成年人只参加普通家庭、学习和成长事件；不进入成人候选池。权力/债务不能代替同意，不做性暴力玩法或真实投毒方法。
- 下列“史据”只证明局部制度；“改编”是游戏建议。史料不等于本作自动采纳的规则；不制作未成年人亲密机制，也不把古代局部社会当作今天整个国家。权力与社会冲突的改编保留玩家选择及相应后果，不预设唯一正确剧情。

## 明制灵感宫城

定位：明代宫廷（1368–1644）启发的架空制度，不混入清代八旗选秀与固定后妃员额。

1. 六局职业：文书、礼仪、衣物、膳食、陈设、制作形成独立技能和晋升，熟练前辈带新人。史据有六局一司及女史文书职责；职位不等于伴侣身份。[故宫《明代宫人的荣与辱》](https://img.dpm.org.cn/Uploads/File/2020/02/19/u5e4cf83d95325.pdf)
2. 典礼协作：宴会、册封、节庆触发跨部门备料、排班、礼仪失误与补救，亲疏关系影响帮忙意愿（改编）。
3. 内廷关系：后妃名位、官职、亲密度和政治影响分账；名号与制度随时期变化，不能套一条通用升级链。亲属、同僚、师徒均能成网。[故宫《论明代后妃制度与宫人命运》](https://www.dpm.org.cn/Uploads/File/2019/12/15/u5df5ea459ab6d.pdf)
4. 家庭世代：孕期休息、照护替班、孩子教育、长辈养老与亲属扶助；亲子身份、抚养关系、财产与储位分别记录，怀孕不自动晋位（改编）。
5. 宫务问责：库存短缺、工作争议由账册与证人推进核查、申辩、补偿，不靠随机定罪（架空简化，非历史司法复刻）。

## 日式幻想汤屋与町街

定位：《千与千寻》式跨时代幻想；町人生活借鉴江户，保留现代设备，不追求单一年代复原。

1. 汤屋职业：清扫、备浴、洗衣、厨房、接待、账房形成可换班的工序；设备故障、客流与同事关系改变一天（幻想改编）。
2. 邻里生活：长屋互助、街摊、借书、消防、季节祭礼串联工作和社交；社群信誉影响借物、托管和调解。史据支持长屋多职业邻居互助及町街、节庆活动。[江户东京博物馆常设展](https://www.edo-tokyo-museum.or.jp/en/p-exhibition/)
3. 演艺事业：音乐、舞蹈、戏剧、茶席表演、师承与预约；艺伎/艺妓不能等同于性工作者。游戏内相关付费陪伴角色统一成年人。[京都官方艺妓介绍](https://kyoto.travel/en/travel-inspiration/a-night-of-luxury-culture-with-kyotos-geiko-maiko/)
4. 家业交接：恋爱与家业合伙分开，孕育/育儿触发顶班；年长店主训练接班人、交接账本与责任。东北村落研究显示户主继承方式存在地区差异；移用到汤屋是设计改编，不宣称全国统一长子制。[Okada与Kurosu家庭继承研究](https://doi.org/10.1017/S0268416098003099)
5. 町内协调：失物、租金与工作争议经邻里见证、协商、赔付处理，避免把神灵老板写成中国式皇帝（改编）。

## 古埃及神庙与工匠聚落

定位：以新王国代尔麦地那的工匠家庭为社会参考；金字塔可作为更早遗迹或架空建筑，不能把新王国王陵工匠材料直接说成吉萨建塔制度。

1. 工匠职业：接图、备料、雕刻/绘饰、验收；书记登记出勤与口粮，技能、可靠性和协作影响分工（据史料改编）。
2. 粮食与权力：欠发口粮影响家庭与士气，可集体请愿、停工、补发、复工；有拉美西斯三世时期纸草记录，不能概括所有劳工。[都灵埃及博物馆罢工纸草](https://collezionepapiri.museoegizio.it/en-GB/section/Papyrus-Collection/History-and-content/Highlights-Turin-Strike-Papyrus/)
3. 家产与申诉：女性可持有财产、订约、诉讼；以契据、证人与家庭关系处理分产。法律行动能力不等于日常权力完全平等。[大都会《古埃及艺术》第9页](https://www.metmuseum.org/-/media/files/learn/for-educators/publications-for-educators/the-art-of-ancient-egypt.pdf)
4. 孕育与宗教：家庭照护、护佑物制作、节庆游行与祭司工作分开；塔沃里特/贝斯是生育保护信仰，游戏祝福不是医学疗效（同上，第27页）。
5. 跨代家庭：孩子学习、长辈传艺、丧亲互助、遗产争议和纪念；寡妇处境因年代、阶层和亲属而异，别写成自动继承或必然无权。[UCL丧偶与继承证据](https://www.ucl.ac.uk/museums-static/digitalegypt/age/agewidow.html)

## 凡尔赛灵感绿白王室庄园

定位：17–18世纪法国王室庄园灵感，不代表所有法国人；绿白是本作美术选择。

1. 礼仪与社交：邀请、座次、称谓、觐见与居所影响能遇见谁；出席和履职可积累信任，失礼可以修复。[凡尔赛宫廷成员](https://en.chateauversailles.fr/discover/history/key-dates/courtiers)
2. 官职与继承：一些职务可继承或购买，重要任命需批准；职务资格、家产、王位继承与私人好感分别计算，不是送礼直升（同上）。
3. 庄园职业：园丁、陈设、衣饰、音乐与宴会服务；修剪、备花、物资预算、庆典筹备带来可见成果。[凡尔赛园林与林苑](https://www.chateauversailles.fr/preparer-ma-visite/parcours-conseils/jardins-bosquets-individuel)
4. 家庭与关系：配偶、非婚伴侣、子女、照护者和公众认知分开；孕期照护、保育与教育也能发展职业。史例有王室保育者及子女身份获正式承认，不能一键等同获得王位继承权。[凡尔赛曼特农展资料，第3页](https://www.chateauversailles.fr/sites/default/files/file/av-maintenon-150419-bd-planche.pdf)
5. 名誉与问责：流言只能改变知情者的判断，须有传播路径；工资/契约争议通过管事核账、证人、申诉与赔偿处理（架空简化）。
