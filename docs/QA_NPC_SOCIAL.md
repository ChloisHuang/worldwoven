# W07 首批：近身回应与交谈

本批只实现靠近时短暂侧目、基于真实角色的交谈及恢复原活动。吃喝、睡眠、轮班与交接仍未实现。没有新增对话框架、访客印章、岗位引擎或计分公式。

- 新增 `npc-social.js`：每次经过短暂关注，不持续围观；只对同层、近距、可见的实际人物开放 E / 触摸打招呼。旧站点仍可体验，不能隔层暂停离岗员工。
- `characters.js` 仅增加平滑头部注视输入：头偏转上限 0.68 弧度，抬低头上限 0.16 弧度，躯干/手部工作目标不跟随转动。无目标时平滑恢复。
- 空闲者可暂歇交谈；走动、做饭、交接、已坐卧/入浴的人回应当前工作并继续。射场角色只作忙碌回应，箭矢与取箭流程不停。E / 触摸结束、Escape、直接走开均释放会话。
- 日本新运营模块使用 `conversationActorId`，动态来客沿用其真实 actor / station ID；服务任务负责保留路线、计时和物品，本助手不复制调度引擎。

验证选择：这是交互状态与共享头部动画改动，保留两项低成本回归，针对原来的远程停工问题、临时来客消失、穿墙/隔层交谈、持续凝视与会话退出。

1. `node tests/npc-social.mjs` 通过：距离/层高/视线、访客创建移除、短暂注视与身后限制、工作忙碌继续、恢复岗位计时
2. `QA_RESOURCE_WINDOW=granted-by-owner node --experimental-vm-modules tests/npc-social-main.cjs` 通过：生产 main 的 E / 触摸开关、手动移动退出、Escape、空站点无远程暂停、真实日本员工移动中回应不停止
3. 单一日本场景、三帧正常 TPS（50°、4.6 米、轻微绕人物观察）人工检查通过：接近 → 侧目 → 回到原工作方向；头/衣领无明显穿插，手部工作姿态不变。最终带渲染运行约 6 秒、645 MiB，使用进程树 175 秒 / 1.2 GiB 限额

测试只使用模拟 DOM 与真实本地 WebGL；未声称手机浏览器验收。已有椅子、共享汤池、行走与碰撞证据复用，本批没有重跑整国矩阵。原日本协作圈验证已通过；新订单适配器的合同字段已对齐，最终合并时只补做新订单适配器受影响的近距交谈与恢复检查。
