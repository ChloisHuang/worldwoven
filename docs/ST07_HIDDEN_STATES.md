## 分开的状态

- 知名度是实际知道此人的身份集合。服务、受害、真实目击/报告及原已完成交谈记忆形成认识；不靠全图广播增加人数。
- 声望按每位知情者对实际履约、尊重、伤害的评价保存，与好感、信任和厌恶分别保存。无观察者上下文不返回全世界平均分。只有调用方已经有真实阵营成员时才支持对那些知情成员聚合，当前没有新造阵营。
- 道德倾向由本人实际行为的关照、尊重、守信三个分量留下原因与回执。正常有偿履约仅有微量守信证据，不将收入或受欢迎程度换成“善良”；拒绝、撤回、无钱和无责中断中性。原封存巡牌的实际盗取即使无人目击也改变本人守信；没有给缺席者评价。后续真实警卫收到报告只增加其自身知识，不重复给行为人记过；已经真实披露的过错也能进入原道歉路径，不要求亲眼看见。
- 支持者必须是已完成谈话中明确表示支持的实际 NPC。原话、事件、当时已知过错留在原关系记忆；现在的信任/界限、死亡/换人以及后来知悉的新过错可以使支持失效。服务累积分高、玩家的支持、缺席虚构人物均不能增加支持者。原身份记录随正常世界存档保留，跨地区不重新造人。
- 健康仍归原独立病程系统；身体状况不换算为社会总分。

旧存档保留关系、收据和已知身份，不从旧好感倒推出从未记录过的道德或明确支持。社会收据仍按稳定 ID 永久去重，最新可读原因有界；没有宣称整个世界存档有界。

## 真实后续动作和反应

四个新选项接原 ST01 真实 7–10 秒面对面交谈、原接受/拒绝、暂停/离岗许可、取消和一次保存完成：

1. 询问是否愿意支持我的做法：必须有原已完成相处、对方知悉的真实行为、当前关系/信任和声望。对方仍按本人兴趣与态度回答，谈话接受不等于支持。
2. 重新谈谈彼此的立场：需要先前明确立场；新过错在完成时重新读取，可以保留或撤回支持。多个原 NPC 控制器的立场以同一世界时钟合并，不用各自局部时钟互相覆盖。
3. 交流实际做事的经验：双方都有实际工作经历或玩家已有职业技能，且当前关系及已知行为允许才出现。完成产生原关系后果，不凭谈话虚增技能/工资。
4. 谈谈最近身体的不适：真实游戏症状才出现。沿原休息话题回应，不凭谈话发药或立即治愈。

既有邀请接受权重只增加一个小幅、定向的有效支持因素；知情声望也只进入原观察者决策。实际未修复的失信/伤害禁用外貌接受加成；原年龄、当次同意、拒绝和撤回规则不变。本人累积行为只微调原 ST05 严重实际矛盾后的克制门槛，仍须原最近过错、距离/可见与安全离岗，不凭道德值无中生有发动冲突。

没有隐藏状态条。原问候会记得有效支持或实际失信；新谈话明确表达支持或保留意见；健康仍用简短症状和实际休息/照护表现。
