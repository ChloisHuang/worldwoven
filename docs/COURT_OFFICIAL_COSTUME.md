# 文官服饰：原创造型依据

实际查看大都会艺术博物馆《Portrait of a Gentleman》（明代，16或17世纪，藏品 51.39.4）的官方图片：<https://www.metmuseum.org/art/collection/search/48939>；图片地址 <https://collectionapi.metmuseum.org/api/collection/v1/iiif/48939/2269991/main-image>。提取圆领整身袍、横向双翼黑帽、前胸方形鸟纹补子和硬质牌带。馆方说明画中是双鹤补子，可能表示一品，但肖像可能夸大身份，不能据此将游戏中两人定为一品。

亚洲艺术博物馆对明代文官肖像的说明同样列出双翼黑帽、带具和鸟纹补服：<https://education.asianart.org/resources/the-court-of-the-ming-dynasty-1368-1644/>。本次看过的实际图像为上面的大都会馆藏；没有把另一馆藏的文字说明当成图片验收。

顾衡与许知远使用专属 `court-official-long-robe`：近直筒圆领长袍、宽整袖、黑靴、前后方形原创长颈鸟纹补子和浅色牌带。补子不宣称具体品级。黑帽有完整冠身和宽横翼；少量短髭与修整下颏须只附加在这两名已设定为成年男性的文官身上，随其已有肤色、发色与面形贴合。原脸部、身体参数、骨架、身份随机种子与普通男性角色头部不改动。服装、纹样均为原创参数几何，馆藏图片未用作游戏资产。

服装与短须合入现有蒙皮批次；帽子挂在既有头骨上，调用方负责在移除角色前释放附件。帽子材料、几何、色阶纹理均在释放时清理。待实际渲染检查直立、行走、用餐/读书与背面后记录验收结果。
