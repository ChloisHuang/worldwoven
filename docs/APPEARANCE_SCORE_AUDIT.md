# C02 评分与肤色独立性核验 · 2026-10-04

针对“随机人物高分基本是深肤色”的实玩反馈，核验源版本 `373c269`。未找到评分或生成耦合，不修改肤色分布、用户审美权重、随机算法或存档。此结论不表示人物侧脸、后脑、形变幅度已经合格。

- 同一组形态参数，仅换18种肤色与4种体型：4组代表参数共288次，严格同分。单独改变实际生成器的肤色抽样位，其他外观字段与分数完全不变；单独改变体型抽样位也不改颜色、形态或分数。
- 玩家按钮调用生产 `randomizePlayerAppearance(..., Math.random, ...)`，体型→原六项→候选四项→肤色等依次独立抽取，再抽服装。正式/候选分别13/17次外观抽取，另加1次服装；世界种子不参与玩家重随机，也没有按分筛选肤色。NPC颜色与形态使用不同前缀及具名字段盐，哈希有最终混洗；旧身份与版本盐不改。
- 当前仍只有原六项入分：下巴宽、腿长、眼睛大小、整鼻大小、鼻宽、眼窝深度。新四项 `chinLength`、`chinProjection`、`noseBridgeHeight`、`noseTipSize` 均不入分，端点核验保持原分。`noseSize` 缩放整个鼻部的横向、高度和前突；`noseWidth` 额外调横宽；`noseTipSize` 只调局部鼻头。高分不能保证新鼻梁高度、鼻头或下巴侧面符合期望。

生产按钮函数抽出执行，只有渲染与时钟占位；保留实际外观生成器与服装抽样。Node v24.19.0，运行时原生 `Math.random`，`--random-seed=13013`，未用测试专用PRNG替代产品。两个入口各500万次，颜色三组按18色的RGB亮度排序等分，每组6色，不作种族推断。

候选/正式总体≥90分分别445/401人，分数与肤色亮度相关系数−0.000452/+0.000240；18种颜色均出现≥90分。18肤色×4体型的72个联合组平均分范围49.891–50.111 / 49.896–50.090，未见体型共因把高分集中到特定肤色。高分是稀有尾部事件，各色或联合组的少量90分样本仍有较大误差，不能要求每组发生率严格一样，也不能据此重现用户当时几次点击或证明所有浏览器历史随机流。

复核：`node tests/appearance-score-independence.mjs` 默认只跑小型因果断言；加 `--samples=5000000` 与上述 Node 种子可复跑统计，输出逐肤色、体型、联合组、≥80/≥90分率。既有 `random-appearance.cjs`、`npc-random-appearance.cjs`、`appearance-score-visibility.cjs` 通过。无产品代码变更，未运行构建、3D、全游戏或真机测试；新四项评分含义仍须明确后再修改，C01/C02形变与美术保持开放。
