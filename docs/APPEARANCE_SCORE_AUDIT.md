# C02 评分与肤色独立性核验 · 2026-10-04

针对“随机人物高分基本是深肤色”的实玩反馈，先核验源版本 `373c269`。未找到评分或生成耦合，没有为肤色调整分数、分布或随机算法。随后用户明确“小鼻子”是鼻窄、鼻翼小、鼻头小，但鼻梁清晰高挺，据此增加显式候选评分v2；此结论不表示人物侧脸、后脑、形变幅度已经合格。

候选 `?character-preview=1` 使用v2：原六项加小鼻头、高鼻梁两个方向，共八项等权；下巴长度/前突仍无单向评分偏好。玩家本次随机可见分、NPC及来客内部计算均显式选v2，普通入口及未传options的调用保持v1六项。候选标签用“鼻翼大小”与“鼻部宽度”区分下鼻体大小和整鼻横宽，配合形变修复 `ff83db7` 的下段鼻翼/鼻体三轴控制，不再把缩小鼻翼等同于压低鼻梁。

分数是派生值，未持久化新版本，也不改存档身份、肤色、种子、外貌值或NPC生成版本。旧数据缺新键取中性1；**跨评分版本不保证同分**，例如旧六项全优且缺鼻梁/鼻头字段，v1为100、v2为88。正式入口仍逐值兼容旧分；候选数据写入原有隔离session空间。界面不新增公式或审美标准说明。

- 同一组形态参数，仅换18种肤色与4种体型：4组代表参数共288次，严格同分。单独改变实际生成器的肤色抽样位，其他外观字段与分数完全不变；单独改变体型抽样位也不改颜色、形态或分数。
- 玩家按钮调用生产 `randomizePlayerAppearance(..., Math.random, ...)`，体型→原六项→候选四项→肤色等依次独立抽取，再抽服装。正式/候选分别13/17次外观抽取，另加1次服装；世界种子不参与玩家重随机，也没有按分筛选肤色。NPC颜色与形态使用不同前缀及具名字段盐，哈希有最终混洗；旧身份与版本盐不改。
- 以下大样本审计记录的是变更前v1：当时新四项均不入分，`noseSize` 还是整鼻缩放，90分不能保证新鼻梁/鼻头侧面符合期望。v2现已纠正鼻梁与鼻头的评分方向，形变修复独立交付；不将旧统计冒充v2高分率。

生产按钮函数抽出执行，只有渲染与时钟占位；保留实际外观生成器与服装抽样。Node v24.19.0，运行时原生 `Math.random`，`--random-seed=13013`，未用测试专用PRNG替代产品。两个入口各500万次，颜色三组按18色的RGB亮度排序等分，每组6色，不作种族推断。
