# W09 首批健康与照护接入

本系统中的「余烬倦怠」「雾铃困倦」「空谷乏意」和「滞露不适」都是虚构游戏病症。阶段、体质、暴露量和恢复速度仅用于游戏平衡，不对应现实诊断、治疗方法或药物剂量。

## 实际玩法

- 玩家和地区内的真实 NPC 沿用原来的身份编号；健康不会重建人物、改衣着或降低玩家行走速度
- 症状出现在玩家地点卡下方和患病 NPC 的原有头顶状态中。坐下、躺下或已实际入座的泡汤休息会加快恢复；走向座位本身不算休息
- 医馆只有把原编号单对应的同号云纹包当面交付给玩家，才开始一段有限的支持性照护。写单、备好纸包、站在柜台附近、取消问诊均不产生此效果；重新读档不会重复领取效果。照护逐步帮助恢复，不会把病症立即清零
- 玩家与中国酒楼两位真实来客的饥饿来自同一个共享日需源；两来客的旧生活决策只读取此饥饿，不能用另一条饥饿曲线或未接入点心动画缓解。其他NPC仍沿用各自既有生活需求，尚未迁入共享生理需求。疲劳与休息继续沿用现有系统

## 共享日需首段（中国实作，其他供给待接）

- 共享玩家身份在当前活动世界随模拟时钟连续累积；世界地图、后台、离线不补时。两位酒楼来客只在中国加载时累积，离开中国后暂停，不用跨国时间一次补成久饿。
- 数值留在存档内部，地点卡只显示「有些饿了／很饿了／久未进食」「该如厕了／如厕拖延较久」。日需低频读钟；不为此每帧重抽NPC选择或重扫全场导航。
- 中国玩家与顾谨、周棠吃完云来楼的真实付费餐单才缓解饥饿。回执绑定订单号、餐品、收款、实物mealId与完整食用；送到、开吃、取消或只做动作均不算吃完。每人的最新食用回执耐久保存，清洗、清单轮换、重进不重复缓解。
- 两位来客吃饱后保持原生活选择；饿且空闲、结束当前承诺后才续点实际有钱支付的饭。原铜钱预算不重置，不足会显示无法点餐。没有增加岗位或替工作流程强行调度全体NPC。
- 如厕复用静宜后宫二层独立净室的真实瓷座、两扇不透明门与浴间全帘；局部脚踏为现有偏高瓷座提供脚部支撑。玩家在活动清单选择「如厕」或走到净室再互动；两位来客在空闲且需要时用原导航步行前往。同一设施只容一人，门帘未闭或旁人进入不能完成；E、移动和离区取消不缓解。完整8秒后才写唯一回执，保存失败重试同号，半程重载中止而非补完。
- 久饿和久拖如厕会分别逐步增加「空谷乏意」「滞露不适」的游戏风险，两者均不传染；满足需求降低后续风险，既有病程仍逐步恢复。只有雾铃困倦沿原真实互动事件传播。
- 首段自动满足范围是中国酒楼这两位来客；共享玩家状态跨国，但日本/法国/埃及的实物食用、如厕供给，以及其他岗位NPC的交班后生理流程仍待逐项接入。原泡澡、茶点、学习、装饰厨房动作不能被当成新日需供给。病假代班、家庭照护、过量进食和全面卫生玩法仍开放。

## 暴露从哪里来

健康只接收已经发生的真人物交互事件，事件包含明确的会话或订单编号、两位参与者、累计实际交互秒数。四国共同的 NPC 对话只记录玩家主动开始且仍有效的谈话；忙碌 NPC 的简短应答最多记录 1.15 秒。路过注视、同桌、同房、站在附近均不产生接触。对话原有距离、楼层和遮挡资格仍由交互系统判定。

中国药铺接入助手与玩家实际交付同号纸包的执行阶段；等单、备好、取消后停留、已交付状态，以及读取历史照护收据都不产生新接触。暂停后继续交付，累计的也只有真正当面交互的时间。

健康时钟不再逐帧枚举全场人物配对，不读位置或检查视线。没有交互事件时，没有传播接触检查。雾铃困倦仍只有发病阶段可以传播，余烬倦怠仍不传染；潜伏、发病、恢复、照护和免疫继续按模拟时间推进，不按帧抽签。停止生成新来客的虚构「雾铃驿」离屏暴露，保留旧存档中已有的旅途记录与病程。

每个事件来源是串行会话流，编号严格递增；保存最新编号、参与者和已处理时长，同一进度重复更新、较旧事件或读档都不能重新累计。将来如有并发订单，须分别使用来源编号；当前没有新增通用多人接触系统。

## 存档与边界

玩家、已见过的永久 NPC 状态一直保留。来客仅保留八份近期健康与旅途记录，当前仍在汤馆的真实来客优先保留，不因住得久而被较新的离场者挤掉。新到访只登记身份，不触发传染。

健康每五秒模拟时间保存，并在离开地区、页面隐藏和页面离开时写入。换地区后，已知人物的病程可随当前游玩时间自然进展，但离场人物没有接触暴露；世界地图、后台和关闭游戏时不推演病程。状态描述展示症状与照护，不展示隐藏阈值和潜伏状态。

本批没有接入病假、请人代班或家庭照护。底层建议字段仍只是建议，任何现有岗位、轮休覆盖、工作订单和交班流程均继续由原系统负责。日本泡汤配料也没有被变成医馆照护。
