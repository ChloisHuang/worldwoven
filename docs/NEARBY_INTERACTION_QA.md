## 审图入口

`/qa/nearby?case=cn-nearby` 自动打开 852×393 的独立 iframe；其他基础状态是 `cn-menu`、`jp-nearby`、`conversation`。界面提供重开、测量、真实按钮点击、菜单关闭及内容滚动。`frame=1` 仅打开该独立视口。

画面必须明确标为“非实机 · Mesa 背景 + 真实产品 DOM/CSS · 仅内存选择”。背景 PNG 来自生产场景正常第三人称镜头；前景直接挂载候选产品 UI 模块，没有另外重画菜单。业务以有限内存夹具承接回调，不运行游戏 main，不读取或写入游戏存档。

QA 发布应使用隔离的候选模块和 CSS，保持生产入口、线上版本及站点受众不变。PNG 和 JSON 为独立 QA 静态资源；打包后的入口须从 `/qa/nearby/` 获取它们。
