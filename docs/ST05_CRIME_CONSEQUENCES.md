# ST05 · 犯罪、追捕与地下小牢房

状态：开发候选，未发布；必须以本文件最终定向验证记录为准，不把原 ST05 缩成一次取物或随机故事。

## 原需求及本批边界

原 `PROJECT_CHECKLIST.md` ST05：记录实际违法、发现、原警卫／锦衣卫追捕、拘捕后果，并建设小规模实际可达的地下牢房。用户另明确：伤害须是实际虚构事件，目击／呼救／距离与查捕、牢房联动，不能只有剧情台词。

本批接入：

- 四国玩家和现有非儿童 NPC 的近身、同场、无遮挡推搡。玩家有明确后果文案与可取消准备时间；实际接触成立后才写伤害。
- NPC 自主行为读取本人对实际对象的严重负面关系、近期真实过错和本人可靠性，不凭颜值、国家、贫富、岗位或随机骰子生成犯罪。只有原控制器允许离岗的人能发起；工作中的人仍能成为实际受害者／目击者。
- 既有健康系统产生有界、非致命、不传染的擦伤，按实际模拟时间休息／既有照护恢复；原关系记录真实受害者和实际见证者，可沿原定时道歉继续修复。
- 中国封存柜的单件巡牌另提供实际有主物品的有限拿取、归还、拘捕时收缴。物品归属保存，不生成金钱或免费交易。
- 真实目击只发生在事发现场、同场景、同楼层范围和无遮挡视线内。受害者可以呼救；警卫须在实际听见范围，或本人见证。之后只有原见证者与警卫能依据真实再次看见的位置更新线索；丢失视线只走最后见到的位置，有限搜索，不追踪隐藏坐标。
- 中国原锦衣卫沈砚／陆衡及原正式职位的合法继任者，在停射且可安全离岗时实际追赶。近身且看见嫌疑人才拘捕，忙于不可中断原服务者先保原岗，安全交接后押送。
- 拘捕者与警卫使用原碰撞／寻路／楼梯实际进入地下候审空间；不传送。守卫在栏门外，嫌疑人真实进入候审间才关门、计时；有限留置后开门，实际沿楼梯回公共庭院才结束。

不扩入 ST06 尚未确认的骚扰／威胁替代提案，不制作性暴力、血腥、刑讯、虐待或致命战斗；地下黑市、司法职业、警察组织和其他国家新执法岗位属于后续独立范围。本批不增加这些人物、职业或服务收费。

## 保存与失败边界

案件、实际证据、有限物品归属与健康待处理回执先保存再生效。健康及关系各按唯一事件去重，最后确认案件回执；任何一步保存失败保留原状态或可安全重放的待处理项。重载不重伤、不复制物品、不重复处罚金钱。

追捕路线失败解除临时控制并保留待查真实线索；不把失败当已押送。离开国家／离线不消除案件，也不补留置时间。已开始的留置只能由实际模拟时间完成；再次进入同一国家重新绑定同一个人和原空间。
